# Rubric — UI/UX design

| Criterion | Weight | Gate |
|---|---|---|
| Visual hierarchy (one clear idea per screen) | 25 | yes |
| Typography (scale, weights, readability) | 20 | no |
| Color (restraint, contrast, state clarity) | 20 | yes |
| Spacing and layout (system multiples, alignment) | 20 | no |
| Motion and feedback (purposeful, 150–300 ms) | 15 | no |

Anchors: 90+ = portfolio-grade, would ship as the reference · 70 = solid,
minor polish notes · 50 = rework the weak criterion · <50 on a gate
criterion (hierarchy, color/contrast) = hard fail, however nice the rest.
