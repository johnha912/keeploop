# Rubric — software engineering

| Criterion | Weight | Gate |
|---|---|---|
| Correctness (does it do what the card said) | 40 | yes |
| Simplicity (no speculative layers) | 20 | no |
| Tests (regression coverage for the change) | 20 | no |
| Clarity (names, structure, one idea per diff) | 20 | no |

Anchors: 90+ = would merge without comment · 70 = merge after minor notes ·
50 = rework the weak criterion · <50 on a gate criterion = hard fail.
