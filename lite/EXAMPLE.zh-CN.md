# keeploop-lite：一个示意示例

> **示意示例。** Mai 是虚构的用户，这段对话是手写的，用来展示一轮的大致样子。它不是真实聊天的记录。分数是 Mai 的评分表给出的分数，不是销售结果。部分回复有删节。

Mai 在她小区的 Facebook 群里卖自制香蕉面包。她把 `KEEPLOOP-LITE.zh-CN.md` 贴进了一个新对话。

---

**AI：** 你好！请把你想改进的东西原样贴过来，并告诉我它是给谁看的。

**Mai：** 我在小区群里发的 Facebook 帖子：“出售香蕉面包。私信我。”

**AI：** 谢谢。更好的版本能帮你做到什么？现在哪里让你不满意？

**Mai：** 没人注意到，每次都有人问价格，我想多接点单。控制在 30 字以内，大家刷得很快。

**AI：** “多接单”从文字上看不出来，所以我建议改为给“让下单更容易”的地方打分。你的字数限制就作为一个门槛。

```
1. 吸睛：第一行让邻居停下来不再往下刷
2. 信息清楚：价格、大小、自取日期和下单方式都写明了
3. 可信：有一个具体、真实的细节，说明是自家做的、新鲜的
门槛：30 字以内
```

团队：本地营销顾问（提出）、文案写手（制作）、正在刷群的忙碌邻居（评分）。

这就是我们每一轮都沿用的评分表吗？团队可以吗？（是 / 修改）

**Mai：** 是

**AI：** **忙碌的邻居：独立评分。**

| 标准 | 分数 | 证据（引用） |
|---|---|---|
| 吸睛 | 2/10 | “出售香蕉面包。”只是个平淡的标签 |
| 信息清楚 | 2/10 | “私信我。”说了怎么下单；没有价格、大小或日期 |
| 可信 | 0/10 | 看不出是自家做的或新鲜的 |
| 门槛：30 字以内 | 通过 | 6 字 |
| 总分 | 4/30 | |

更可靠的做法是说 **审核**，让一个新对话在不知道我们期望什么的情况下来打分。

*（AI 打印出记录本，完整内容见文末。）*

---

**Mai：** 下一轮

**AI：** **本地营销顾问。**

```
假设卡 - 第 1 轮（本地营销顾问）
改动：加一行，写明价格、大小和自取日期。
应改善：信息清楚，因为大家总在问价格。
如何判断：信息清楚从 2/10 往上升。
可能变差：预计没有
需要你提供：真实的价格、大小和自取时间
开始吗？（是 / 否）
```

**Mai：** 是。一条 $8，周六 9 点到 12 点自取。

**AI：** **文案写手。**

> 出售香蕉面包。$8 一条，周六 9–12 点自取。私信我下单。

**忙碌的邻居：独立评分。**

| 标准 | 分数 | 证据（引用） |
|---|---|---|
| 吸睛 | 2/10 | “出售香蕉面包。”没有变化 |
| 信息清楚 | 8/10 | “$8 一条，周六 9–12 点自取。私信我下单。”；大小只写了“一条” |
| 可信 | 0/10 | 看不出是自家做的或新鲜的 |
| 门槛：30 字以内 | 通过 | 14 字 |
| 总分 | 10/30 | |

**判定：保留。** 门槛通过，且 10 高于目前最佳（4）。
没有新经验。

---

**Mai：** 下一轮

**AI：** **本地营销顾问。** 可信最弱，只有 0。

```
假设卡 - 第 2 轮（本地营销顾问）
改动：开头加一句简短、真实的话，讲配方的来历。
应改善：可信（也许还有吸睛），因为现在看不出是自家做的。
如何判断：可信从 0/10 往上升。
可能变差：30 字门槛，如果这句话太长。
需要你提供：关于配方或烘焙的一个真实细节
开始吗？（是 / 否）
```

**Mai：** 是。这是我外婆的配方，我每周都做，做了 10 年，孩子们总抢最后一片。

**AI：** **文案写手。**

> 用我外婆的配方烤的。我每周都烤，已经烤了 10 年，孩子们到现在还抢最后一片！出售香蕉面包。$8 一条，周六 9–12 点自取。私信我下单。

**忙碌的邻居：独立评分。**

| 标准 | 分数 | 证据（引用） |
|---|---|---|
| 吸睛 | 5/10 | “用我外婆的配方烤的。”用一件私人的事开头 |
| 信息清楚 | 8/10 | “$8 一条，周六 9–12 点自取。私信我下单。” |
| 可信 | 7/10 | “我外婆的配方”、“每周都烤，已经烤了 10 年” |
| 门槛：30 字以内 | **不通过** | 36 字 |
| 总分 | 20/30 | |

**判定：舍弃。** 总分更高，但门槛没通过，而没通过门槛的版本永远不会保留。已舍弃。我们回到最佳版本（第 1 轮）。

```
KEEPLOOP-LITE 记录本
作品：在小区群出售自制香蕉面包的 Facebook 帖子
评分表（自第 0 轮起锁定，满分 30）：

3. 可信：有一个具体、真实的细节，说明是自家做的、新鲜的
门槛（通过/不通过）：30 字以内
团队：本地营销顾问（提出）、文案写手（制作）、忙碌的邻居（评分）
目前最佳：第 1 轮，10/30（吸睛 2，信息清楚 8，可信 0）

| # | 改动 | 分数 | 判定 |
|---|---|---|---|
| 0 | 基准（原样贴入） | 4/30 | 基准 |
| 1 | 加了价格、大小和自取那一行 | 10/30 | 保留 |

- L1（第 2 轮）：家庭故事让可信从 0 升到 7，但帖子变成了 36 字。下次试着用一句短话说完。

最佳版本（第 1 轮）：

```

说 **下一轮**、**状态**、**审核** 或 **新基准**。
